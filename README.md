# Bid Simulator

投标价格模拟器，一个纯前端单页工具，用于做低价审查、价格评分、手动改价分析和历史对比。

## Features

### 低价审查
- 三条触发线，全部在页面上显式显示阈值数值：
  - ① 低于全部有效投标报价算术平均值的 `_`%
  - ② 低于次低报价的 `_`%
  - ③ 低于采购项目最高限价的 `_`%
- 触发 1 条标记为「需澄清」，触发 2 条及以上标记为「重点审查」
- 触发线数值直接展示，方便判断某个报价为什么没触发

### 价格评分规则
| 规则 | 原始分公式 | 满分 |
|------|-----------|------|
| 最低价法 | 最低有效报价 ÷ 当前报价 × 100 | 100 |
| 平均价贴近法 | (1 - \|当前报价 - 平均价\| ÷ 平均价) × 100 | 100 |
| 性价比法 | min(100, 最高限价 ÷ 当前报价 × 50) | 100 |
| IQR中间价法 | (1 - \|当前报价 - 中位数\| ÷ 中位数) × 100 | 100 |
| **评标价偏离扣分法** | 见下 | 可配置（默认 30） |

**评标价偏离扣分法**对应招标文件常见的评标价打分条款，页面上 4 个参数可按招标文件改：

| 参数 | 页面字段 | 默认值 | 说明 |
|------|---------|-------|------|
| 评标价满分 K | `评标价满分 K（分）` | 30 | 报价正好等于 Q 时拿满分 |
| 低价偏离扣分系数 | `低价偏离扣分（每1%扣）` | 0.1 | 报价**低于** Q 时每偏离 1% 扣几分 |
| 高价偏离扣分系数 | `高价偏离扣分（每1%扣）` | 0.2 | 报价**高于** Q 时每偏离 1% 扣几分 |
| 评标价口径门槛 | `超过 ___ 家去极值` | 5 | 有效报价 ≤ N 家取全部均值，超过 N 家去掉一个最高和一个最低 |

- 评标价 Q：按上面的门槛决定口径
- 报价低于 Q：`K = 满分 - [(Q-q) ÷ Q] × 100 × 低价系数`
- 报价高于 Q：`K = 满分 - [(q-Q) ÷ Q] × 100 × 高价系数`
- K 最低为 0，保留 3 位小数（四舍五入）
- 参数只在选中该规则时显示，并随历史轮次一起存取；规则说明里的公式跟着参数走，不会和实际计算对不上

> 注意：低价审查①用的"算术平均值"和评标价 Q 在超过门槛家数时不是同一个数，页面上分别标注，别混用。

### 手动改价分析
选择本轮改价对象、低价竞争者、目标对象，填入改价报价，实时重算目标与竞争者的分差、第一名归属和改价对象的审查风险。

### 历史对比
- 保存每一轮的参数和各家得分，本地 localStorage 累计
- 支持按轮次名称筛选、加载还原、删除
- 「各家得分差对比」表横向展示多轮结果，含排名、得分、进度条和与第一名的分差

## Run

直接打开 `index.html` 即可使用。

## Tech notes

- 纯静态单文件，无构建步骤、无外部依赖
- 风险标签按**索引**绑定（`reviews[idx]`）而非按名字查找，避免同名投标人串号
- 投标人名称在插入 DOM 前做完整 HTML 转义（`& < > " '`）
- 报价 ≤ 0、最高限价 ≤ 0 直接拦截并提示
- 历史记录按**原始输入顺序**保存，加载后行序不变
- 评分规则只有 `scoreScenario` 一份实现，`doCalc` 和手动改价分析共用，避免规则改一处漏一处
- 数字输入用 `numOr()` 取值（空/非法回落默认值），不用 `||`，否则用户填 `0` 会被当成空值
